# 「StyleAtlas 前端风格图鉴」首屏样例优先布局重构方案

## 一、 核心重构目标
解决目前右侧主区域顶部文字说明卡片与多层控制栏占用近 `520px` 高度、导致每次切换风格都需要向下滚动才能看到实际页面样例的问题。重构后**首屏顶部开销压缩至 `110px` 以内**，保证一点击左侧风格，右侧第一眼直接呈现完整的交互式页面样例。

---

## 二、 界面布局调整细节 (`/src/App.tsx`)

### 1. 顶部第一层：单行紧凑风格标题栏（Compact Style Header Bar）
- **左侧**：一行展示风格编号与中英文名称（如 `01. 扁平化设计 (Flat Design 2.0)`）、所属分类标签以及一句精炼的一句话核心特征（`tagline`）。
- **右侧**：并排放置高频操作按钮：
  - `一键复制风格 Prompt`（带复制成功态反馈）
  - `16 风格速查矩阵`

### 2. 顶部第二层：一体化紧凑演练场工具栏 + 即时展示页面样例画布（Above-the-Fold Live Sandbox）
- **合并单行工具栏**：
  - **左侧（样例切换组）**：将原先占满一行的 4 张大卡片精简为紧凑单行分段胶囊切换条：
    - `01 · 着陆页 (Landing)`
    - `02 · 仪表盘 (Dashboard)`
    - `03 · 交互组件 (Interactive)`
    - `全景展开 (All 3)`
  - **右侧（视图与代码控制组）**：同一行集成 `交互预览 / JSX 源码` 切换、`复制当前 JSX` 按钮以及 `桌面宽屏 / 紧凑视口` 切换。
- **主画布紧随其后**：工具栏下方零冗余间距，直接渲染 `StyleExampleRenderer` 实际页面样例，并在画布底部附带紧凑的一行「当前样例场景说明与核心技法提示」。

### 3. 画布下方区域：风格深度解析、色板与 Tailwind 组件配方
- 当用户看完首屏的实际页面样例后，向下滚动即可依次查阅：
  1. **风格深度解析与适用指南**：完整流派背景简介（`summary`）、代表标杆品牌（`representativeBrands`）、最佳适用场景（`bestFor`）与避坑不推荐场景（`notRecommendedFor`）。
  2. **核心视觉特征、5 色 Token 色板（点击即复制）与排版/圆角/阴影规范**。
  3. **可直接复制的 Tailwind CSS 组件类名配方、必做项/禁忌项（Do's & Don'ts）与本地开发备忘录**。
- 同步更新顶部锚点导航顺序：`页面样例演练场` → `风格详解与色板` → `Tailwind 组件配方`。
