# 创建项目 `README.md` 方案

## 一、 新增文件
- **`/README.md`**：在项目根目录创建简洁、清晰的中文 `README.md` 文档。

## 二、 `README.md` 包含内容
1. **项目标题与在线访问入口**：
   - 置顶醒目展示 GitHub Pages 线上地址：[https://huanghuanghuhu.github.io/style-atlas/](https://huanghuanghuhu.github.io/style-atlas/)
2. **核心功能概览**：
   - 收录 **16 大业内公认主流前端设计风格**（涵盖 Flat 2.0、Shadcn/Zinc、Material 3、Microsoft Fluent、Bento Grid、瑞士国际主义、社论杂志、极光暗黑、新拟态、空间毛玻璃、3D 黏土、经典拟物化、新粗野主义、Win95 复古桌面、CLI 极客终端、赛博朋克 HUD）。
   - 每套风格配备 **3 套完整可交互页面样例（共 48 套）**，支持 **桌面 (`100%`) / 平板 (`768px`) / 手机 (`390px`)** 三档 `@container` 响应式预览与 JSX 源码一键复制。
   - 内置双风格同屏对比器、16 风格全景 Tailwind 参数速查表、AI 提示词（Prompt）复制及本地开发备忘录。
3. **本地开发与构建指令**：
   - `npm install --legacy-peer-deps`
   - `npm run dev` / `npm run build`
